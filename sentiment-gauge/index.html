Audience Reaction Gauge

Usage Instructions

Include the component script in your HTML:

<script src="sentiment-gauge.js"></script>

Add the element to your page:

<sentiment-gauge id="gauge"></sentiment-gauge>

Update its data using JavaScript:

const gauge = document.getElementById('gauge');
gauge.data = {
  thumbsup: 45,
  heart: 10,
  fire: 5,
  pray: 0,
  ok: 0,
  funny: 2,
  neutral: 1,
  thumbsdown: 1,
  frown: 0,
  rage: 0
};
